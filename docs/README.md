# docs

| File or folder | What it is |
|---|---|
| [`DECISIONS.md`](DECISIONS.md) | One line per decision a later session might undo (date, what, why). The best place to learn why something is the way it is. |
| [`SPEC.md`](SPEC.md) | The original day-one spec. The product has changed since (real map, My World, Report); where they differ, the README and DECISIONS win. |
| [`PRD-report.md`](PRD-report.md) | Product requirements for the Report feature, including the demo plan and privacy notes. |
| [`TECH-PARAGRAPHS.md`](TECH-PARAGRAPHS.md) | How we use Gemini, Tiger Data, MBTA and Boston data, Vercel and Claude Code, in short paragraphs. |
| [`BU-PLACES.md`](BU-PLACES.md) | Places picked for the pixel landmarks near the demo venue. |
| [`FRICTION-LOG.md`](FRICTION-LOG.md) | Onboarding friction found while testing (written when the product was still called T Party). |
| `screenshots/`, `report-screens/` | Screenshots of the app, kept for the pull requests and the write-up. |
| `knit-assets/` | The knitted art: originals and an overview (`album.png`). The resized files used by the app are in `public/assets/`. |
| `bu-pixel-reference/` | Style anchor and prompt for the BU pixel landmarks. |

Feature-level docs live next to the code: each `src/features/<name>/README.md`, and Report's `EDGE-CASES.md`.
